# Golden Set Labeling Guide

## Intent Labels
1. **Playback/Technical Bug** — app crashes, skipping, freezing, broken features
2. **Account Access** — login, password, 2FA, lockout issues
3. **Billing/Subscription** — charges, refunds, plan/subscription issues
4. **Content Availability** — missing songs/podcasts, licensing/region issues
5. **Feature Request/Complaint** — wants a feature, dislikes a product decision
6. **Service Outage** — widespread known issue, "is it down for everyone"
7. **Other** — genuinely doesn't fit above (e.g., praise, spam, unrelated topics,
   or ambiguous cases where no category clearly applies after considering all six)

## Reference Reply Standard
- Categories with many valid phrasings (Playback Bug, Feature Request):
  provide key facts the reply must contain, semicolon-separated
- Categories with a clear standard flow (Account Access, Billing):
  provide a full reference reply in SpotifyCares' typical tone

## Escalation Decision Rubric
Escalate = yes if ANY apply:
1. Mentions a specific dollar amount or explicit refund request
2. Implies account compromise (hacked, unauthorized access)
3. Contains anger/threat language (profanity, "cancelling", legal threats)
4. Customer has already gone back and forth 2+ times without resolution

Otherwise escalate = no.
