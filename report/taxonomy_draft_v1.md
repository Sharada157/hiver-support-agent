# Draft Intent Taxonomy v1

1. Playback/Technical Bug — app crashes, skipping, audio issues
2. Account Access — login, password, 2FA problems
3. Billing/Subscription — charges, refunds, plan issues
4. Content Availability — missing songs/podcasts, licensing
5. Feature Request/Complaint — wants a feature, dislikes a change
6. Service Outage — widespread known issue
7. Other — anything that doesn't fit
